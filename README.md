## 🚀 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/beorsi/portfolioDiw.git
   cd portfolioDiw
   ```

2. Abra diretamente no navegador:
   ```bash
   # Opção 1 — abrir o arquivo
   start index.html

   # Opção 2 — usar extensão Live Server no VS Code (recomendado)
   ```

> Não há dependências de build. É um projeto 100% HTML/CSS/JS estático.
